# Intuition

I wanted to create a simple webpage with a heading, paragraph, and card. I used HTML to build the structure and CSS to style the page with light and dark theme colors.

# Approach

I created the webpage using HTML and styled the elements using CSS. I added different styles for the light and dark themes. Due to limited time, I could only complete the HTML and CSS parts. JavaScript functionality and localStorage are not implemented yet.

# User Guide:

- Open `index.html` in your web browser.
- View the heading, paragraph, and card.
- The page displays the basic layout and styling.
- The theme toggle functionality is not available yet.
